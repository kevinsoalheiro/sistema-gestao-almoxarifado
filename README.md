# Sistema de Gestão de Almoxarifado e Ferramentas — PDS2/UFMG
Sistema desenvolvido em C++ para gerenciar o cadastro, o armazenamento, a movimentação e o controle de ferramentas e materiais de um almoxarifado. O projeto utilizará programação orientada a objetos, organização modular e mecanismos de validação de dados.
