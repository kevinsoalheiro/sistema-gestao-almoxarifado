# Sistema de Gestão de Almoxarifado e Ferramentas

## Integrnte
- Kevin Alves Soalheiro

## Sobre o projeto

O projeto consiste em um sistema simples de gerenciamento de almoxarifado, desenvolvido em C++ para a disciplina de Programação e Desenvolvimento de Software 2 (PDS2) da UFMG.

Escolhi esse tema porque o controle de materiais e ferramentas é importante para organizar o estoque e evitar problemas como retiradas sem registro ou falta de materiais.

Nesta primeira versão, implementei o cadastro de materiais e ferramentas, o controle de empréstimos e devoluções e algumas consultas de estoque. O sistema utiliza classes e conceitos de programação orientada a objetos.

Os testes foram desenvolvidos utilizando doctest, e a cobertura do código é verificada com gcovr.
